1. Overview — Kya hai ye page

Mockup me: "My Performance" page with 3 tabs: Performance, My Goals, Class Comparison.

Existing Next.js me: Ek simple DataTable hai Performance.jsx — course list with score, pace, teacher, progress bars. Click karo toh modal khulta hai assignment details ke saath.

K5 version me: Bahut zyada naya hai — animated hero section, star rating system, streak tracker, achievement badges, stat tiles, redesigned course list with inline detail (modal hata ke). Lekin Tab 2 (My Goals) aur Tab 3 (Class Comparison) ke liye koi backend API nahi hai.

2. Teen Tabs ka Breakdown

Tab 1: Performance ~80% API Available

Ye tab fully buildable hai existing APIs se (minus kuch calculated fields). Sections:

  1. Hero Section — animated SVG scene + rotating motivational tips + 3 pills (Progress, Streak, Scores)
  2. Score Card — 5-star rating + word ladder (Superstar / Great / Good / Getting there / Let's practise)
  3. Streak Card — flame icon, consecutive on-time submissions, dot trail, streak badges
  4. Achievements — 5 medal badges (3 earned, 2 locked)
  5. 4 Stat Tiles — Average score %, Assignments submitted, Courses ahead/behind, Days left
  6. Course List — progress ring, star rating, score %, on-time count, "View assignments" button
  7. Course Detail — inline expand (no modal!), assignment breakdown table

Tab 2: My Goals BLOCKED — No Backend API

Mockup me dikhaya hai goal-setting UI: student apne goals set karta hai (score targets, submission targets). Lekin backend me koi API nahi hai goals save/load karne ke liye. "Coming Soon" placeholder lagana padega.

Tab 3: Class Comparison BLOCKED — No Backend API

Class ke saare students ka aggregate comparison. Backend me koi API nahi hai class-wide data ke liye (privacy reasons bhi ho sakte hain). "Coming Soon" placeholder lagana padega.

3. Old vs New — Kya Badla Hai

Old (Existing Next.js)

  • Simple DataTable — rows with columns
  • Score = plain percentage text
  • Pace = GIF icons (forward.gif, behind.gif)
  • Progress = flat progress bars
  • Course click → Modal with assignment table
  • Grade history → nested sub-modal
  • No streak tracking
  • No achievements / badges
  • No star rating
  • No motivational tips
  • Desktop table + mobile cards

New (K5 Mockup)

  • Visual dashboard — cards, rings, animations
  • Score = 5-star rating + word-level label
  • Pace = text labels (Ahead/On Track/Behind) + colored styling
  • Progress = circular ring (donut SVG)
  • Course click → Inline expand (no modal)
  • Grade history → same inline or nested card
  • NEW: Streak card — on-time submissions ka streak
  • NEW: Achievement badges — 5 medals
  • NEW: Star rating system — percentage → stars convert
  • NEW: Motivational tips — rotating text in hero
  • Single responsive layout — K5 theme tokens

4. API Mapping — Kaunsa API Kahan Lagega

UI SectionAPI EndpointKey Fields
Course List (sab courses) {schoolId}/dashboard/parent/student-academic-performance courseName, score, progressPace, teacherName, endDate, remainingDays, pendingAssignment, progressGradable, progressAllActivity, lmsEnrollmentId, lmsCourseId
Score Card (average) Same API ↑ (aggregate client-side) Saare courses ka score average karo → star rating compute karo
4 Stat Tiles Same API ↑ (aggregate client-side) Average score = mean of scores, Submitted = sum, Ahead count = progressPace === "Ahead" filter, Days left = min of remainingDays
Course Detail (expand) {schoolId}/dashboard/get-student-progress-report-detail totalAssignment, submiteAssign, pendingAssign, upcomingAssign, passesAssign, failedAssign, enrollments.enrollment.grades.items.item[]
Grade History (per assignment) {schoolId}/dashboard/get-progress-report-grade-history grades.grade[] → achieved, possible, percent, lastactivitydate
Streak Koi direct API nahi ❌ Progress detail se assignment items ka submissionStatus + duedate use karke approximate streak calculate ho sakta hai
Achievements Koi direct API nahi ❌ Frontend computed: Early Submitter (sab time pe), Clean Sweep (sab passed), Perfect Score (100%), Halfway (50%+ done), On Target (pace Ahead/OnTrack)
Note: student-academic-performance sirf Agilix Buzz LMS providers (courseProviderId 36/37/38) ke liye data return karta hai. Baaki providers ke liye empty list aati hai — ye existing behavior hai, K5 me bhi same rahega.

7. Blocked Items — Kya Nahi Ban Sakta

Tab 2 "My Goals" — FULLY BLOCKED
Backend me goals save/load ka koi API nahi hai. Naya endpoint banana padega (lekin rule hai: don't create new backend endpoints). Isko "Coming Soon" placeholder banana padega.
Tab 3 "Class Comparison" — FULLY BLOCKED
Class-wide aggregate data ka koi API nahi hai. Privacy concerns bhi ho sakte hain. "Coming Soon" placeholder.
Streak Counter — PARTIALLY BLOCKED
Direct "streak" API nahi hai. Lekin get-student-progress-report-detail se assignment items milte hain jisme duedate aur submissionStatus hota hai. In se approximate streak calculate ho sakta hai. Accurate nahi hoga lekin reasonable approximation ban sakti hai. Agar bahut complex lage toh simple "X assignments on time" count dikhao without streak logic.
