📊 Section 1: Existing Backend APIs ka Review

1.1 Main Performance API

POST /{schoolUUID}/dashboard/parent/student-academic-performance
Controller: ClientDashoboardParentController.java
Util: DashboardStudentUtil.getPerformance(userId, standardId)
Response: StudentAcademicPerformanceDetailsDTO

Response Fields (StudentAcademicPerformanceDTO):

FieldTypeDescription
lmsEnrollmentIdStringAgilix Buzz enrollment ID
lmsCourseIdStringAgilix Buzz course ID
courseNameStringSubject/Course ka naam
scoreStringCurrent overall score (%)
teacherNameStringAssigned teacher
teacherGenderStringMr./Ms. ke liye
startDateStringCourse start date
endDateStringCourse end date
remainingDaysStringKitne din bache hain
pendingAssignmentIntegerPending assignments count
progressGradableStringGradable activities ka % complete
progressAllActivityStringAll activities ka % complete
progressPaceString"Ahead" / "OnTrack" / "Behind" / "GettingStarted"

Wrapper: StudentAcademicPerformanceDetailsDTO — courseProviderId (Integer) + List<StudentAcademicPerformanceDTO>

⚠️ Sirf Agilix Buzz providers (36, 37, 38) ke liye data aata hai. Baaki providers ke liye empty list aati hai.

1.2 Course Detail API (Progress Report)

POST /{schoolUUID}/dashboard/get-student-progress-report-detail
Controller: ClientDashboardAzlixbuzzController.java
Payload: { studentUserId, lmsUserId (=enrollmentId), entityId (=courseId) }
Response: Agilix Buzz XML → enrollments → grades → items

Per-item fields (assignment level):

submitteddate✅ pmSubDate
timespent (hh:mm:ss)✅ pmTime

Tiles data bhi aata hai: totalAssignment, submiteAssign, pendingAssign, upcomingAssign, passesAssign, failedAssign

1.3 Grade History API

POST /{schoolUUID}/dashboard/get-progress-report-grade-history
Payload: { itemId, enrollId }
Response: Individual assignment ki grade history

1.4 Weekly Progress Reports API

POST /{schoolUUID}/dashboard/parent/weekly-progress-reports-detail
Response: StudentWeeklyProgressReportDetailsDTO { studentWeeklyProgressReports: [...] }
Har report mein: daysType, reportStartDate, reportEndDate, createdDate, playloadUrl (PDF URL)

1.5 Semester Marks APIs

GET /{schoolUUID}/dashboard/get-semester-marks/{uniqueUUID}
GET /{schoolUUID}/dashboard/get-pre-semester-marks/{uniqueUUID}
Controller: ClientDashoboardMarksController.java
Ye rendered HTML page return karte hain (Thymeleaf template), direct API data nahi
