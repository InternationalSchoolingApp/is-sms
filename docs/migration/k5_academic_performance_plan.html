1. Overview — Page Structure

Mockup mein 3 tabs hain:

  1. Performance pmT1 — scores, streak, achievements, courses list, course detail
  2. My Goals pmT2 — goal setting dialog, weekly tracker, per-course goals
  3. Class Comparison pmT3 — anonymized class standing, histogram, per-course compare

Existing page kya karti hai: Simple DataTable — courses list (name, score, pace, teacher, end date, remaining days, pending assignments, progress bars). Sirf Agilix Buzz LMS providers (36/37/38) ke liye data aata hai. Course click pe modal mein assignment details + grade history.

2. Existing Backend APIs (3 endpoints)

API 1: Course List
POST /{schoolUUID}/dashboard/parent/student-academic-performance
Payload: { userId, studentUserId }
Response: { details: { courseProviderId, studentAcademicPerformances: [...] } }
Course fields: courseName, score, progressPace (Ahead/OnTrack/Behind), teacherName, teacherGender, endDate, remainingDays, pendingAssignment, progressGradable, progressAllActivity, lmsEnrollmentId, lmsCourseId
Code: hooks/useStudentAcademicPerformance.js → services/dashboardApi.js → getStudentAcademicPerformance()
EXISTING — yeh primary data source hai
API 2: Course Detail (assignments)
POST /{schoolUUID}/dashboard/get-student-progress-report-detail
Payload: { studentUserId, lmsUserId, entityId } + UNIQUEUUID header
Response: { totalAssignment, submiteAssign, pendingAssign, upcomingAssign, passesAssign, failedAssign, response: { enrollments: { enrollment: [{ grades: { items: { item: [...] } } }] } } }
Assignment item fields: itemid, title, duedate, submissionStatus, status, unitPercent
Code: components/student/PerformanceProgressModal.jsx → dashboardApi.js → getStudentProgressReportDetail()
EXISTING — course detail ke liye
API 3: Grade History
POST /{schoolUUID}/dashboard/get-progress-report-grade-history
Payload: { itemId, enrollId } + UNIQUEUUID header
Response: { response: { grades: { grade: [{ achieved, possible, percent, lastactivitydate }] } } }
Code: components/student/PerformanceGradeHistoryModal.jsx → dashboardApi.js → getProgressReportGradeHistory()
EXISTING — grade history sub-modal ke liye

7. Implementation Plan

Phase A: Tab 1 — Core Performance (existing APIs se, fully buildable)

  1. K5Performance.jsx — main page component with 3 tab headers (Tab 2, 3 = "Coming Soon")
  2. K5PerfHero.jsx — hero card with SVG scene + rotating tips (course data se)
  3. K5PerfScoreCard.jsx — score ladder, star rating, avg score, word level, encouragement
  4. K5PerfStatTiles.jsx — 4 stat tiles (avg score, submitted/pending, courses ahead/behind, days left)
  5. K5PerfCourseList.jsx — course rows: progress ring, stars, pace chip, teacher, "View assignments"
  6. K5PerfCourseDetail.jsx — inline detail view replacing modal: header, 6-category donut, assignment table
  7. K5PerfGradeHistory.jsx — grade history K5-styled sub-modal

APIs: Saare 3 existing — koi naya endpoint nahi chahiye.
Data flow: useStudentAcademicPerformance (hook) → courses list → K5 components. Course click → getStudentProgressReportDetail → detail view. Assignment click → getProgressReportGradeHistory → grade history.

Phase B: Tab 1 — Enhancements (optional, client-side calculated)

  1. K5PerfStreakCard.jsx — streak from assignment submission dates (needs lazy-loading detail per course)
  2. K5PerfAchievements.jsx — 5 medal badges, unlock conditions from course data
  3. Enhanced motivational tips with streak + specific assignment data
  4. Per-course streak chips in course list

Note: Expensive — har course ka detail fetch karna padega for streak/badges. User se puchho ki yeh priority hai ya nahi.

Phase C: Tab 2 — My Goals (BLOCKED — backend API needed)

Goal save/load + weekly progress tracking ke liye backend chahiye. Filhaal "Coming Soon" placeholder. Tab header dikhega, content mein friendly message.

Phase D: Tab 3 — Class Comparison (BLOCKED — backend APIs needed)

Class avg, ranking, distribution — sab naye endpoints chahiye. "Coming Soon" placeholder.
