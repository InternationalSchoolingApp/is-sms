Communications (Inbox): JSP se Next.js migration

Legacy Inbox page (emails, notifications, announcements, WhatsApp, Sent, Compose aur Reply) ko is-rest-api (jQuery page) se is-sms (Next 16, React Query, Tailwind v4, shadcn ui) me le jaana hai. Sirf existing backend endpoints use honge, koi naya endpoint nahi banega.
Branch feature/version_1_3_0_phase4 Sidebar pageLink inbox (+ inbox-compose) Status Sirf plan: app code change nahi hua Date 2026-11-12

1 Summary

Legacy Inbox ka server side already achha bana hua hai: InboxController ({schoolId}/dashboard/inbox/*) hamesha token wale user par kaam karta hai (InboxService.viewer() → CurrentIdentity.getUser), inbox module right check karta hai, aur har id (email, attachment, reply, recipients) dobara check karta hai. Isliye ye migration zyada tar front-end rewrite hai. Bas teen chhote Next.js route handlers chahiye un kaamon ke liye jo Server Action se nahi ho sakte: multipart send, sandboxed email body, aur attachment download.

5 Security review

Legacy backend me pehle se safe hai (jaisa hai waisa rakhna)
  • Payload se koi user id nahi padhi jaati: har endpoint InboxService.viewer() (token user) use karta hai aur inbox module right check karta hai.
  • childUserId viewer ke apne children se match hota hai; email, attachment, star aur reply ids check hote hain ki viewer unhe dekh sakta hai ya nahi.
  • Send me server har recipient dobara check karta hai, daily cap, subject/message length, file count, size, extension aur file signature bhi.
  • Email body Content-Security-Policy: sandbox …; script-src 'none' ke saath aati hai aur iframe me bina allow-scripts ke dikhti hai.

8 Attachment download example

Abhi legacy reader har attachment ko naye tab me /dashboard/inbox/attachment?payload=… se link karta hai; backend viewer ko dobara check karta hai aur 302 se 5-minute S3 link par bhejta hai. is-sms me browser ke paas backend token nahi hai, isliye Next server ye call karega aur file sahi naam ke saath stream karke wapas dega.

8.1 Route handler (server)

// app/api/inbox/attachment/route.js  (planned)
import { NextResponse } from "next/server";
import { getAccountSession, serviceKeyHeaders } from "@/lib/auth/session";
import { hasBackendOrigin, resolveServerBackendOrigin } from "@/utils/backendOrigin";

const S3_HOSTS = (process.env.INBOX_ATTACHMENT_HOSTS || "s3.amazonaws.com").split(",");
const plain = (status, message) => NextResponse.json({ message }, { status });

export async function GET(request) {
  const me = await getAccountSession();
  if (!me?.accessToken || !me?.schoolUUID) return plain(401, "Your session has been logged out");
  if (!hasBackendOrigin()) return plain(500, "The backend is not configured.");
  const payload = request.nextUrl.searchParams.get("payload");   // opaque, email answer se
  if (!payload) return plain(400, "The attachment link is missing.");

  const base = await resolveServerBackendOrigin();
  const check = await fetch(
    `${base}/${me.schoolUUID}/dashboard/inbox/attachment?payload=${encodeURIComponent(payload)}`,
    { headers: { ...serviceKeyHeaders(), Authorization: `Bearer ${me.accessToken}` },
      redirect: "manual", cache: "no-store" });

  if (check.status !== 302) {                    // 403 / 400 / 503: backend ka text dikha sakte hain
    return plain(check.status === 401 ? 401 : check.status, await check.text());
  }
  const link = new URL(check.headers.get("location") || "", "https://invalid");
  if (link.protocol !== "https:" || !S3_HOSTS.some((h) => link.hostname.endsWith(h))) {
    return plain(502, "This attachment cannot be opened just now.");
  }
  const file = await fetch(link, { cache: "no-store" });
  if (!file.ok || !file.body) return plain(502, "This attachment cannot be opened just now.");

  // Stored naam "123456789_homework.pdf" jaise hote hain: 9-digit prefix ke baad wala hissa dikhao.
  const stored = link.pathname.split("/").pop() || "attachment";
  const shown = decodeURIComponent(stored).replace(/^[0-9]{9}_/, "");
  const headers = new Headers({
    "Content-Type": file.headers.get("content-type") || "application/octet-stream",
    "Content-Disposition": `attachment; filename*=UTF-8''${encodeURIComponent(shown)}`,
    "Cache-Control": "no-store",
    "X-Content-Type-Options": "nosniff",
  });
  const length = file.headers.get("content-length");
  if (length) headers.set("Content-Length", length);
  return new NextResponse(file.body, { status: 200, headers });  // stream, buffer nahi
}

8.2 Client side (hook + button)

// utils/inbox.js (planned)
export async function downloadInboxAttachment(attachment) {
  const response = await fetch(`/api/inbox/attachment?payload=${encodeURIComponent(attachment.payload)}`);
  if (response.status === 401) { markSessionExpired(); throw new SessionExpiredError(); }
  if (!response.ok) throw new Error((await response.json().catch(() => ({}))).message
                                    || "This attachment cannot be opened just now.");
  const blob = await response.blob();
  const url = URL.createObjectURL(blob);
  const a = Object.assign(document.createElement("a"), {
    href: url, download: attachment.name.replace(/^[0-9]{9}_/, ""),
  });
  document.body.appendChild(a); a.click(); a.remove();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}
